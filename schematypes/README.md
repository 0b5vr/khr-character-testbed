# schematypes

This directory contains TypeScript type definitions for KHR_character schema elements.
Definitions are not exhaustive.

Schema source: https://github.com/KhronosGroup/glTF/pull/2512

Target revision: [2026-11-03 / `7ab5368`](https://github.com/Kjakubzak/glTF/tree/7ab5368a87d1d303dff33ec5f9aad42752e84c78/extensions/2.0/Khronos). Runtime validation also checks constraints that TypeScript types and JSON Schema cannot express.

khr-character-testbed: viewer

This is a tentative viewer for KHR_character, a proposed extension for glTF. The purpose of this viewer is to test the extension and provide feedback to the proposal, so it may not be a fully featured viewer for KHR_character.

Currently supported features:

  • Basic glTF rendering using Three.js GLTFLoader
  • KHR_character_expression: Control character expressions using sliders
  • KHR_character_expression_joint: Support joint-based expressions
  • KHR_character_expression_morphtarget: Support morph-based expressions
  • KHR_character_expression_texture: Support texture UV-based expressions. Thanks to
  • VRMC_character_expression_lookat: When "Look-at" is set to "camera", the character's expression is automatically controlled to follow the camera
